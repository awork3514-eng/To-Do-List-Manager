# To-Do List Manager

A simple To-Do List Manager developed using Java.
This project helps users manage their daily tasks efficiently.

## Features
- Add new tasks
- View all tasks
- Delete tasks
- Manage daily activities

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Generics

## Project Structure

```
To-Do List Manager/
│
├── src/
│   ├── Main.java
│   └── TodoListManager.java
│
├── .gitignore
└── README.md
```

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Run `Main.java`.

## Usage

After running the application, use the following commands:

| Command  | Description              |
|----------|--------------------------|
| `add`    | Add a new task           |
| `view`   | View all tasks           |
| `delete` | Delete a task by number  |
| `exit`   | Exit the application     |
